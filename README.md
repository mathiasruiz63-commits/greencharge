# Green Charge

Paquete del proyecto académico ficticio de Business Tech UDD.

## Descargar

[Descargar GreenCharge.zip](https://github.com/mathiasruiz63-commits/greencharge/raw/refs/heads/entrega-greencharge/GreenCharge.zip)

Descomprime el ZIP y abre **GreenCharge/ABRIR-SITIO.html** para ver la maqueta. Puedes reenviar el ZIP completo.

Incluye cuatro páginas y la vista de categoría Artículos, seis fichas de soluciones, noticia, imágenes conceptuales, borradores importables a WordPress y datos/recetas para dos visualizaciones de Flourish.

**Estado:** es un paquete de trabajo, no un sitio publicado en WordPress.com. Las dos visualizaciones reales de Flourish aún no se han creado. Las instrucciones completas y los pendientes están dentro del ZIP. No se contrató ningún servicio de pago.
