# Green Charge

Paquete del proyecto académico ficticio de Business Tech UDD.

## Descargar

[Descargar GreenCharge.zip](https://github.com/mathiasruiz63-commits/greencharge/raw/refs/heads/entrega-greencharge/GreenCharge.zip)

Descomprime el ZIP y abre **GreenCharge/ABRIR-SITIO.html** para ver la maqueta. Puedes reenviar el ZIP completo.

Incluye cuatro páginas y la vista de categoría Artículos, seis fichas de soluciones, noticia, imágenes conceptuales, borradores importables a WordPress y datos/recetas para dos visualizaciones de Flourish.

**Estado:** es un paquete de trabajo, no un sitio publicado en WordPress.com. Las dos visualizaciones reales de Flourish aún no se han creado. Las instrucciones completas y los pendientes están dentro del ZIP. No se contrató ningún servicio de pago.

## Preparar WordPress en lote

[Descargar GreenCharge-Automatico.zip](https://github.com/mathiasruiz63-commits/greencharge/raw/refs/heads/entrega-greencharge/GreenCharge-Automatico.zip)

Extensión temporal para Chrome que actúa en el editor ya autenticado del usuario. No requiere compartir contraseñas ni configurar tokens. Incluye las tres imágenes y trabaja sobre las cuatro páginas y la noticia ya importadas. Guarda una copia previa, conserva cambios manuales y comunica pendientes. No crea los gráficos de Flourish.

Descomprimir, abrir `chrome://extensions`, activar **Modo de desarrollador**, pulsar **Cargar descomprimida** y seleccionar **GreenCharge-Automatico**. Después abrir **Inicio → Editar** en WordPress y ejecutar la extensión desde el icono de la pieza de puzle. Instrucciones completas dentro del ZIP y en [automation/LEEME.md](automation/LEEME.md).

Probada con API simulada y ejecución de su lógica en Chromium; la instalación completa quedó sin verificar porque el navegador del entorno bloquea las extensiones descomprimidas. Si el equipo del usuario también impone esa restricción, no debe eludirse. Aún no se ejecutó en el sitio real. Véase [validación y límites](automation/VALIDACION.md).
